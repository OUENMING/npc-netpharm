# 实验 E114–E119（2026-11-14 至 11-15）

鼻咽癌（NPC）网络药理学方案 A 之后的补充检验：用公开治疗队列和单细胞数据，检验 134 个核心靶点与 6 个 hub 的临床相关性。

**状态：AI 初算，尚未人工复核。** 所有数字均为样本内探索性结果，不是独立验证。每个实验先写预注册（`预注册_先于看数据.md`），再看数据；事后追加的修订都在文件里标明。

| 编号 | 内容 | 一句话结果 |
|---|---|---|
| E114 | 三个带治疗信息的 NPC 队列 | 6 个 hub 中只有 PTGS2 与诱导化疗非应答相关（GSE132112，样本内）；134 靶点整体无富集 |
| E115 | PTGS2 独立数据补充检验 | 公开数据里找不到可用的独立验证集 |
| E116 | LINCS 药物信号反转 + 菌群数据可得性 | 预设标准未达；CNP0002119 公开但体量大、人群不同 |
| E117 | 10 个机制模块探针 | 模块层面无信号 |
| E118 | Nature Cancer 2026 交互表 × 核心靶点 | 核心靶点未富集 |
| E119 | GSE150430 单细胞定位 | 肾上腺素受体≈0；PTGS2 主要在单核/髓系，但该定位已有 2024 年先行报道 |

## 重要提示

- PTGS2 与诱导化疗应答的关联已见于 JNCI 2021 的六基因签名，本检验是在 hub 里的重现与扩展，不是首次发现。
- 终点是短期 RECIST 应答，不是生存。
- GSE132112 是上述 JNCI 研究的发现队列，本检验为样本内。
