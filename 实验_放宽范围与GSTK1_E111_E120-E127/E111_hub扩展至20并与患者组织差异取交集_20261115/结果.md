## 3. 对导师三个要求的回答
1. **hub 扩到 10–20**：已做，名单在 `out/hub_ranked_134.csv`。
2. **与患者组织差异取交集**：交集仍只有 PTGS2。想要更多交集，只能放宽到 hub 20 名以外，那就不再是「hub」了。
3. **对接靶点与核心集一致**：保留的对接涉及 6 个靶点（ADRA2A、CA9、GPR84、MAOB、PTGS2、VDR）。**只有 PTGS2 在 H_20 内**；CA9 排第 92、MAOB 排第 34 位，在核心集内但不是 hub；ADRA2A、GPR84、VDR 不在核心 134 内（回接失败或被剔除）。

## 4. 唯一新冒出来的线索：MAOB（探索性，不是结论）
- MAOB 在肿瘤里下调（log2FC −1.54，三芯片元分析 FDR 9.4e-10），5 套数据同向（E82），连到 3 个黄酮类代谢物（刺槐素、芹菜素、染料木素），三者都有对接，PubMed 标题摘要里「MAOB × 鼻咽」检索 0 篇；放宽到 all fields 命中 5 篇，逐篇核对**全是不相关**（帕金森药物试验的鼻咽炎副作用、腭咽闭合等），没有 MAOB 与鼻咽癌的研究记录。
- **但**：MAOB 不是 hub（第 34 位）；与治疗应答无关（GSE132112 AUC 0.454，P=0.51）；对接强度只是预测；一个基因在组织里下调不等于与化疗/放疗结局相关。**它满足「PubMed 里没有人把它和鼻咽癌连起来」，不满足导师要的「与患者结局有明确关联」。**
- 「PubMed 零命中」只代表这个检索式下零命中，不代表没人研究；不写「空白」「首次」。

## 5. 对主线的含义
- 导师要的「后面的靶点里匹配到新的」：**在 hub 口径下没有**；放宽到差异基因口径，只有 MAOB 一个看起来研究少，但没有结局证据。
- PTGS2 仍是唯一同时满足「hub + 患者组织强差异 + 与诱导化疗应答相关 + 有代谢物连接 + 有对接」的靶点，但它在 NPC 里研究不少（114 篇），不新（见 E120）。
- 扩 hub 本身不能产出「正向、确定」的结局关联；要结局关联仍靠 E120 之后的路线（配对数据或医院 IHC）。

## 6. 限制
hub 排名受 STRING 文献偏倚影响；差异基因是肿瘤 vs 正常；PubMed 计数受检索式与别名影响；GSE132112 AUC 是 E114 已有结果的描述性复用，样本内；MAOB 的黄酮代谢物连接来自预测（SEA），未核对生理浓度。
