# E120 · PGE₂–Treg 轴与 PTGS2 稳健性：结果（AI 初算，2026-11-15）

文件：`预注册_先于看数据.md`、`01_bulk.py`、`02_sc.py`、`运行输出_01.txt`、`运行输出_02.txt`、`out/`。环境：numpy/scipy/pandas/statsmodels（临时 venv）；种子 20261116。数据同 E114/E119（GEO 公开）。

## 一句话
1. **PTGS2 的非应答关联在小样本稳健方法下仍成立**（预设判据达成）。
2. **PNAS 的 PGE₂–Treg 轴在诱导化疗队列的 bulk 数据里没有检出**：PTGS2 与 TI-Treg 特征不相关，TI-Treg 特征也不预测应答（两个主检验都阴性，按预注册不改法重试）。
3. 单细胞（GSE150430，15 例）里同向但**未达预设显著性**（主检验 P=0.095）。
4. 同时核实了 Gut 2026 的数据可得性（见 §D）：**配对数据拿不到，需要问作者。**

## A. 第 1 部分：PGE₂–Treg 轴（GSE132112，n=95，非应答 24 / 应答 71）
| 检验 | 结果 |
|---|---|
| P1 Spearman（PTGS2, TIT） | ρ=−0.042，P=0.686 |
| P1 偏相关（控制 CD3、FOXP3） | ρ=−0.066，P=0.527 |
| P2 TIT 对非应答 AUC | 0.523（0.403–0.648），P=0.735 |
| 主检验 BH(2) | q 均 0.735 → **未检出** |
| 参考：PTGS2 与 CD3 / FOXP3 | ρ=0.088 / −0.055（均不显著） |
| 次要（7 基因，BH） | TNFRSF9/18/4、CTLA4、CCR8、IL2RA 均未检出（q 0.665）；**FOXP3 AUC 0.362（非应答者更低），名义 P=0.045，BH q=0.31，不作结论** |
| P3 PTGS2 OR/SD | 2.32 → 加 TIT 2.34 → 加 CD3 2.40 → 加 TIT+CD3 2.48（几乎不变） |

读法：按预注册规则 3，写「本数据未检出」。PTGS2 的非应答关联与 TI-Treg 程序**无关**（PTGS2 效应不随 TIT 校正而变）。这与 E117 里 PTGER2/PTGER4/TIGIT 阴性、PGE₂/COX 模块整体阴性一致：本队列里 PTGS2 信号是**基因特异的**，没有 PGE₂–Treg 下游的整体印记。局限：FFPE 芯片 bulk 里 Treg 程序难与 T 细胞浸润分开（TIT 与 CD3 ρ=0.29）。

## B. 第 2 部分：PTGS2 稳健性（非应答=1，PTGS2 取 z 分数，样本内）
| 模型 | OR/SD（95% CI） | P |

- 注意：Firth 使 OR 从 3.10 收缩到 2.78，说明 3.10 略偏高；以后引用用 Firth 数。仍是样本内，非独立验证。

## C. 第 3 部分：GSE150430 单细胞（15 例，每例 ≥20 个 Treg 细胞）
| 检验 | 结果 |
|---|---|
| **主：PTGS2 最高 5 例 vs 最低 5 例的 Treg TIT_sc** | 中位 1.011 vs 0.783；Mann-Whitney **P=0.095（未达预设 P<0.05）** |
| 全体 Spearman（PTGS2, TIT_sc） | ρ=0.482，P=0.069 |
| 偏相关（控制髓系细胞占比，次要） | ρ=0.547，P=0.043（名义，次要） |
| 参考：PTGS2 与髓系占比 | ρ=0.629 |
| 单基因（Treg 内均值 vs PTGS2） | CTLA4 ρ=0.65；TNFRSF18 0.38；TNFRSF4 0.27；TNFRSF9 0.26；CCR8 0.24（探索，未校正） |
读法：**方向与 PNAS 一致，但主检验未达显著，不能写「复现」**；只能写「同向趋势」。n=15，功效低。PTGS2 患者均值与髓系占比相关（ρ=0.63），分组本身部分反映髓系细胞多少。PNAS 的数据编号未读到，所以也不能说它与本数据独立。

## D. Gut 2026 数据可得性核查（UCD 全文，2026-11-15 读）
- 论文：Lan 等，*Gut* 2026-04-28，DOI 10.1136/gutjnl-2026-338223，PMID 42049488。516 NPC + 263 对照。
- **数据可得性声明**：宏基因组 `PRJCA032292`、RNA-seq `PRJCA027691`，「自发表之日起公开」；代码在 GitHub；其余「向通讯作者 L-QT（tanglq@sysucc.org.cn）索取」。
- **现实**：NGDC 上两个 BioProject 今天（2026-11-15）均显示「not released」（对照项目 PRJCA017950 能正常显示）。**声明与实际不一致。**
- 36 例来源（原文）：「n=36，derived from 54 patients with available pretreatment transcriptomic data via clinical feature matching」；18 vs 18（PMS 高和/或 EBV DNA 高 vs 双低）；组内仅 4/18 的 EBV DNA ≥4000，分组主要由 PMS 区分。**主要发现是 T 细胞耗竭评分（P=0.016）、TCF1（P=0.002）；全文未涉及 PTGS2、前列腺素、COX、Treg（全文检索无命中）。**
- 补充表 S1 有 779 个宏基因组样本的临床元数据（NPC_01…NPC_516，EBV DNA、分期）；S11 只有 36 例的分组汇总，**没有逐患者的菌群丰度、RNA 表达或「宏基因组样本 ID ↔ RNA 样本 ID」对照**。S6 给出差异 KO（含丁酸 K00169、LPS K11719/K03643，核实）。
- 作者代码仓库：`baidefeng/NPC_metagenome` 仅 6 个 Rmd + Rproj，无 `data/`，读取的 `RNA_squencing_data.xlsx` 等文件不在库中。
- 结论：**配对分析需要作者提供**（至少：ID 对照 + 36–54 例处理后丰度表 + RNA 计数/TPM）。邮箱（来自 PubMed 通讯作者行与论文）：tanglq@sysucc.org.cn（论文明确的联系人）、liuyongxin@caas.cn、maihq@mail.sysu.edu.cn。邮箱是否有效未验证。

## E. 综合与写作规则
- **可写**：PTGS2 对诱导化疗非应答的关联在 Firth、bootstrap、留一下稳健（样本内）；在本队列里这一关联与 TI-Treg 程序无关。
- **不可写**：「PTGS2–PGE₂–Treg 轴与应答相关」「复现 PNAS」「PTGS2 介导」；单细胞的趋势只能写「同向未达显著」。
- **新颖性**：PTGS2→TI-Treg 在 NPC 单细胞是 PNAS 的发现；PTGS2 与 IC 应答是 JNCI 2021 的。本实验的新增只有两条**阴性/稳健性事实**，不构成创新点。
- 主要限制：样本内；FFPE 芯片 bulk 对 Treg 程序分辨率差；单细胞仅 15 例。
