# E122 · 每一步都放宽范围再取交集：36 格放宽网格（预注册，先于看数据，2026-11-15）

## 0. 动机
统筹 转述并追问导师意思：不止把 hub 往后扩，而是**流程的每一步都放宽一点，再取交集看有什么留下来**。E111 已只放宽 hub 一步：交集只有 PTGS2。本实验把四步一起放宽，问：放宽到什么程度才会出现 PTGS2 以外、稳定、并且与治疗结局相关的靶点？
**已披露**：E111（hub 单步放宽）、E114（134 核心靶点在三个队列的检验：GSE132112 BH q 无一过，PTGS2 q=0.053）、E120 已看过。**没看过**：250 靶点池的 PPI 排名、36 格交集、250 池在 GSE132112 的单基因检验。

## 1. 放宽的四个维度（固定，共 2×2×3×3=36 格）
| 步骤 | 档位 |
|---|---|
| S1 靶点池 | (a) 核心 134（SEA∩STP∩疾病基因，现行）；(b) SEA∩STP 250（去掉疾病基因过滤） |
| S2 PPI 阈值 | (a) STRING 综合分 ≥0.4（现行）；(b) ≥0.15（STRING 低置信度档） |
| S3 hub 取前 K | K=10、20、30（按平均排名，并列并入） |
| S4 差异基因口径 | D0 现行 is_DEG（三芯片元分析 FDR<0.05、平均\|log2FC\|≥1、三套同向）；D1 去掉 FC 门槛（FDR<0.05 且三套同向）；D2 五套数据随机效应元分析 5/5 同向且 CI 不含 0（E82 全基因表） |
- hub 平均排名：Degree、MNC、Betweenness、Closeness 四算法的排名平均（四算法在 250 节点网络上可算；现行 5 算法 MCC/Stress 在大网络上计算量过大，且 E94 已验证换算法 hub 稳健）。网络 = 靶点池内 STRING 诱导子图（STRING v12.5 取数；现行 134 网络是更早版本 v12，边数可能略有出入，**会先核对 134 网络与旧 1,037 边的重合度并写入结果**）。无边节点不参与排名。
- 每一格：交集 = hub(K) ∩ 差异基因(Dx)，同池内。

## 2. 预注册输出
1. 36 格各自的交集基因清单。
2. 每个基因的**稳定性** = 出现在多少格（/36）。
3. 并集基因（至少出现 1 格）逐个做 GSE132112 治疗应答检验（沿用 E114：非应答 vs 应答的 Mann-Whitney AUC，双侧 P，基因水平=外显子级探针集均值）；并集族内 BH。GSE103611（无转移 vs 转移）、GSE224450（PR vs 非 PR，面板覆盖者）作为独立终点的**描述性**对照，不进主判据。
4. 稳定性与结局的交叉：稳定性≥50%（≥18 格）的基因（以下称**稳定候选**）。
5. 校准：并集族里名义 P<0.05 的个数 vs 期望 5%；另做 2000 次随机对照——从同池里随机抽同样个数的基因，看「名义 P<0.05 的个数」≥ 实际个数的频率。

## 3. 主判据与解释规则（先写定）

## 4. 局限（先写）
放宽越多，交集里随机基因越多，多重检验压力越大，所以以并集族 BH 和随机对照为准；hub≠重要；差异基因是肿瘤 vs 正常；GSE132112 是 JNCI 发现队列（样本内）；STRING 版本不同；4 算法平均排名与现行 5 算法不同。
